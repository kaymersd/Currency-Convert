## 🖥️ Overview

Currency Converter allows users to convert an amount from one selected currency to another through a clean and easy-to-use interface.

The project was developed during my web development studies at DevClub as a hands-on exercise in building interactive applications with HTML, CSS, and JavaScript.

## ✨ Inside the App

- **Currency selection:** choose the currencies used in the conversion.
- **Amount input:** enter the value you want to convert.
- **Interactive interface:** update displayed information based on user actions.
- **Conversion logic:** process the entered amount using the rates configured in the application.

*Note: Conversion accuracy depends on the exchange rates implemented in the current version.*

## 🔍 Built With

| Technology | Purpose |
|---|---|
| HTML5 | Application structure |
| CSS3 | Layout and visual design |
| JavaScript | Application behavior and conversion calculations |

## ▶️ Try It Yourself

You can run the project locally without installing additional dependencies.

1. Download or clone this repository.
2. Open the project folder in your code editor.
3. Launch `index.html` in your browser.
4. Select the currencies and enter an amount.

For local development, you can also use the Live Server extension in Visual Studio Code.
