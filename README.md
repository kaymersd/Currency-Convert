## 🖥️ Overview

Currency Converter allows users to convert amounts between different currencies through a clean and easy-to-use interface.

The project was developed during my web development studies at DevClub as a hands-on exercise in building interactive applications with HTML, CSS, JavaScript, and external APIs.

## ✨ Features

- **Currency selection:** hoose the source and target currencies.
- **Amount input:** enter the value you want to convert.
- **Live exchange rate:** convert between Brazilian Real (BRL), US Dollar (USD), Euro (EUR), and British Pound (GBP).
- **Interactive interface:** update displayed information based on user selections.
- **Input validation:** prevent invalid amounts and conversions between identical currencies.

## 🔍 Built With

| Technology | Purpose |
|---|---|
| HTML5 | Application structure |
| CSS3 | Layout and visual design |
| JavaScript | Application behavior and conversion calculations |
| AwesomeAPI | Retrieve currency exchange rates |

You can try **Currency Convert** directly in your browser:

👉 [https://kaymersd.github.io/Currency-Convert/](https://kaymersd.github.io/Currency-Convert/)

### Run Locally

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser.
4. Select the source and target currencies and enter an amount to convert.

For local development, you can also use the **Live Server** extension in Visual Studio Code.

## 🧠 Development Notes

This project gave me an opportunity to put core JavaScript concepts into practice, especially DOM manipulation, event handling, asynchronous functions, and updating the interface in response to user input.

It also helped me understand how to work with external APIs using fetch(), handle JSON responses, and use exchange rate data to perform currency conversions.
